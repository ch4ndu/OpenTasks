# Changelog - Week 4, 09-08-2026, V. 1.1.0

## Changes

### Two-account data isolation

- Added authentication and durable session restoration for two pre-created PocketBase users.
- Bound the single local Room cache to the active server/account/capability epoch and replaced it transactionally during safe account switches and logout.
- Scoped tasks, attachments, categories, notes, countdowns, tags, and task-tag assignments by owner in PocketBase rules and client requests.
- Added fail-closed account/epoch validation for reminders, notifications, widgets, background sync, imports, and other delayed platform callbacks.

### PocketBase migration and sync

- Added the PocketBase 0.36.7 ownership migration with required two-user inputs, composite owner/local-ID indexes, capability metadata, protected attachment access, and tombstone-only deletion rules.
- Added a production cutover runbook covering backup, account creation, legacy assignment to Account A, authorization probes, rollback, and rollout order.
- Corrected PocketBase record updates to use `PATCH` and added guarded owner-scoped recovery for stale stored record IDs.
- Classified retryable authentication/capability/inventory HTTP responses as connectivity failures so a proven account cache remains available offline.
- Made Settings manual sync await the real sync pass and report record failures separately from connection failures.

### Account and session UI

- Added responsive sign-in, restoration, reauthentication, account switch, and logout states across the shared Compose targets.
- Shows Retry only after restoration fails instead of while restoration is in progress.
- Improved account text-field contrast, landscape surface consistency, and Android system status/navigation bar icon appearance.

### Verification and operations

- Migrated the production PocketBase dataset to Account A, created exactly two accounts, and validated Account B isolation.
- Validated login, account switching, restoration, task visibility, and manual sync on the Android physical device.
- Passed 287 JVM tests, 10 Android unit tests, Android lint and debug assembly, JVM compilation, both iOS ARM64 compilation targets, focused project audit, and the verified Sol final gate.

## Accepted follow-up

Fresh backend-free local-only startup remains deferred. Version 1.1.0 supports offline continuation only after an account has authenticated and the local cache has a durable verified binding.
