## Changes

### Local-only operation and Quick Add

- Released backend-free Local-only startup while retaining the same Room-backed application and explicit optional PocketBase connection flow.
- Added count-only authoritative-connect preview and explicit destructive confirmation before replacing the authenticated destination owner's data.
- Added bounded offline Quick Add parsing for English date, time, and recurrence phrases with removable inference chips and a full-editor escape hatch.

### External input and native boundaries

- Added shared byte, provider-count, filename, and encoded-URL limits for Android, iOS, and JVM share/import paths.
- Replaced whole-file reads with bounded strict-UTF-8 readers and typed localized failures.
- Serialized iOS Share Extension provider aggregation, surfaced provider-load and app-open failures, and retained the deliberate custom-URL transport without adding an App Group.
- Added a timeout- and output-bounded JVM process runner for desktop Calendar commands with deterministic cancellation and child-process cleanup.

### PocketBase lifecycle, cancellation, and diagnostics

- Added an owned account-client session boundary and exact-once cleanup for temporary, detached, replaced, failed, cancelled, and disconnected PocketBase clients.
- Preserved `CancellationException` across affected suspend paths and corrected debounced-sync job ownership cleanup.
- Removed user-authored, imported, navigation-payload, and PocketBase endpoint values from affected diagnostics.
- Added focused Ktor `MockEngine` authenticator coverage without introducing a live-server or disposable-service fixture.
- Removed the unreachable Settings PocketBase URL mutation Actions, UI, DI registrations, and obsolete tests while retaining authenticated endpoint ownership.

### Calendar, recurrence, and UI performance

- Replaced occurrence-by-occurrence countdown projection with anchor/index arithmetic plus bounded adjacent-candidate correction.
- Added immutable calendar row/day projections, stable identity reuse, and background formatting/grouping.
- Moved fixed preview selection and domain-model mapping out of calendar composition; retained only measured-height prefix selection at the layout boundary.

### Toolchain, Android resources, and documentation

- Updated Compose Multiplatform to 1.11.1, RichEditor to 1.0.0, and other compatible catalog dependencies while retaining documented API-36-compatible pins.
- Kept runtime Compose tooling debug-only and verified the exact tooling artifact is absent from the release runtime graph.
- Fixed widget preview/resource lint, added API-31 provider metadata variants, migrated named Instant and Material tab deprecations, and kept lint free of unexplained issues without a broad baseline.
- Added durable architecture, UI, audit, testing, calendar, import/export, and coverage-debt documentation.
- Left repository CI deferred by explicit user decision.

### Verification

- Passed 354 JVM tests and 11 Android unit tests: 365 automated tests total.
- Passed Android lint, debug and release APK assembly, JVM compilation, and both iOS Kotlin ARM64 compilation targets.
- Passed the code-signing-disabled Xcode build for the app and Share Extension without booting a simulator.
- Confirmed release runtime dependencies exclude exact `androidx.compose.ui:ui-tooling`; `ui-tooling-preview` remains available.
- Passed `git diff --check`, focused changed-path audits, and the verified Sol-xhigh final gate.

No emulator, simulator boot, physical device, live PocketBase server, or broad integration harness was used for this release candidate.
